Connect to the R2 bucket

This tool reads and writes the Brewstock image bucket directly from this browser. Credentials are held in memory for this tab only — they are never saved to the site, to disk, or to browser storage.

Advanced

How to create the R2 credentials
  1. In the Cloudflare dashboard, open R2 → your images bucket → Settings → CORS Policy and add the policy shown under Bucket health → CORS policy. Do this first: the browser cannot reach the bucket until it is in place.
  2. Open R2 → Manage R2 API Tokens → Create API token.
  3. Give it Object Read & Write permission, scoped to the images bucket.
  4. Copy the access key ID and secret access key shown once at creation time.
  5. Connect, then run Bucket health → Run connection test to confirm read, write and delete access before processing photos.

This page holds no photos and no credentials of its own. It cannot read or change anything in the bucket without a valid R2 access key, so opening it without the keys only ever shows the sign-in form.
